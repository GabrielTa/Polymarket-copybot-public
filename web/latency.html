⏱️ Latency & Slippage Decay

Is the copy edge perishable?
← Main dashboard   Shadow →   Hybrid →
📖 In plain terms: when a leader bets, we copy them — but a bit later and sometimes at a slightly worse price. The theory: the more time passes (latency) or the more the price moves against us before we fill (slippage), the more the edge is already gone. This page tests that on real copied bets by grouping their actual win/loss by how stale the signal was and how far the price moved. Green ROI = still profitable, red = the edge died. A clear cliff = a mechanical "skip" rule. From data we already store — no fetch.
